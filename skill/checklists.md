# Squad 에이전트별 체크리스트

SKILL.md에서 참조됩니다. 각 에이전트 프롬프트에 해당 체크리스트를 포함하세요.

## CleanCode 전문가
- [ ] 함수/메서드가 20줄 이하인가?
- [ ] 함수명이 동작을 명확히 설명하는가?
- [ ] 변수명이 의도를 드러내는가?
- [ ] 매직 넘버/스트링이 상수화되었는가?
- [ ] 중복 코드가 없는가? (DRY)
- [ ] 단일 책임 원칙을 따르는가?
- [ ] 중첩 깊이가 3단계 이하인가?
- [ ] 주석 없이도 코드가 자명한가?

## Architect 전문가
- [ ] 의존성 방향이 올바른가? (안쪽→바깥쪽)
- [ ] 레이어 간 경계가 명확한가?
- [ ] 인터페이스/트레이트로 추상화되었는가?
- [ ] 순환 의존성이 없는가?
- [ ] 변경의 영향 범위가 최소화되었는가?
- [ ] 설정/환경이 코드와 분리되었는가?

## BugHunter 전문가
- [ ] null/undefined 처리가 안전한가?
- [ ] 에러가 적절히 처리되고 전파되는가?
- [ ] 경계값/엣지케이스가 처리되었는가?
- [ ] 동시성/경쟁 조건 위험이 없는가?
- [ ] 입력 유효성 검증이 되었는가?
- [ ] 보안 취약점 (인젝션, XSS 등)이 없는가?
- [ ] 리소스 누수 (파일, 커넥션 등)가 없는가?

## TestExpert 전문가
- [ ] 핵심 로직에 단위 테스트가 있는가?
- [ ] 경계값 테스트가 포함되었는가?
- [ ] 에러 경로 테스트가 있는가?
- [ ] 테스트가 독립적이고 반복 가능한가?
- [ ] 모킹이 과도하지 않은가?
- [ ] 테스트 이름이 의도를 설명하는가?
- [ ] Given-When-Then 구조를 따르는가?

## PerfTuner 전문가
- [ ] O(n^2) 이상의 복잡도가 없는가?
- [ ] 불필요한 재계산/재렌더링이 없는가?
- [ ] 메모리 누수 패턴이 없는가?
- [ ] N+1 쿼리 문제가 없는가?
- [ ] 적절한 캐싱이 적용되었는가?
- [ ] 대용량 데이터 처리에 페이지네이션이 있는가?

## TypeGuard 전문가
- [ ] 타입이 any/unknown 없이 정확하게 정의되었는가?
- [ ] 제네릭이 적절히 활용되었는가?
- [ ] 유니온 타입이 좁혀져서 사용되는가?
- [ ] null/undefined가 타입 레벨에서 처리되었는가?
- [ ] 타입 단언(as) 대신 타입 가드를 사용하는가?
- [ ] 인터페이스/타입이 과도하게 넓지 않은가?

## ReactPro 전문가
- [ ] 훅 규칙을 준수하는가? (조건부 호출 없음)
- [ ] useEffect 의존성 배열이 정확한가?
- [ ] 불필요한 재렌더링이 없는가? (memo, useMemo, useCallback)
- [ ] 상태가 적절한 레벨에 위치하는가?
- [ ] 컴포넌트가 단일 책임을 따르는가?
- [ ] key prop이 안정적이고 고유한가?

## RustSage 전문가
- [ ] 소유권/빌림 규칙이 올바른가?
- [ ] 라이프타임이 필요 최소한인가?
- [ ] unwrap() 대신 적절한 에러 처리를 사용하는가?
- [ ] unsafe 블록이 최소화되고 문서화되었는가?
- [ ] Clone/Copy가 불필요하게 사용되지 않는가?
- [ ] 동시성 패턴이 안전한가? (Send/Sync, Mutex 사용)

## DocWriter 전문가
- [ ] 공개 API에 JSDoc/Rustdoc이 있는가?
- [ ] 매개변수와 반환값이 문서화되었는가?
- [ ] 사용 예제가 포함되었는가?
- [ ] 에러/예외 상황이 문서화되었는가?
- [ ] README가 프로젝트 구조를 반영하는가?
