# 에이전트별 체크리스트

각 에이전트 프롬프트에 해당 체크리스트를 포함하세요.

## CleanCode
- [ ] 함수/메서드 20줄 이하, 파라미터 3개 이하
- [ ] 변수/함수명이 의도를 명확히 표현
- [ ] 매직 넘버/스트링 상수화
- [ ] 중복 코드 없음 (DRY), 단일 책임 (SRP)
- [ ] 중첩 깊이 3단계 이하, 주석 없이 자명

## Architect
- [ ] 의존성 방향 올바름 (안쪽→바깥쪽)
- [ ] 레이어 경계 명확, 인터페이스/트레이트 추상화
- [ ] 순환 의존성 없음, 변경 영향 최소화
- [ ] 설정/환경 코드 분리

## BugHunter
- [ ] null/undefined 안전한 처리
- [ ] 에러 적절히 처리/전파, 엣지케이스 처리
- [ ] 동시성/경쟁 조건 없음, 입력 유효성 검증
- [ ] 보안 취약점 없음, 리소스 누수 없음

## TestExpert
- [ ] 핵심 로직 단위 테스트, 경계값/에러 경로 포함
- [ ] 독립적/반복 가능, 과도한 모킹 없음
- [ ] Given-When-Then 구조, 이름이 의도 설명

## PerfTuner
- [ ] O(n²)+ 복잡도 없음, 불필요한 재계산 없음
- [ ] 메모리 누수 없음, N+1 쿼리 없음
- [ ] 적절한 캐싱, 대용량 페이지네이션

## TypeGuard
- [ ] any/unknown 없이 정확한 타입, 제네릭 적절 활용
- [ ] 유니온 타입 좁히기, 타입 가드 사용 (as 지양)
- [ ] null/undefined 타입 레벨 처리

## ReactPro
- [ ] 훅 규칙 준수, useEffect 의존성 정확
- [ ] 불필요한 리렌더링 없음, 상태 적절 위치
- [ ] 컴포넌트 단일 책임, key prop 안정적

## RustSage
- [ ] 소유권/빌림 올바름, 라이프타임 최소한
- [ ] unwrap() 대신 에러 처리, unsafe 최소화/문서화
- [ ] Clone/Copy 불필요 사용 없음, 동시성 안전

## DocWriter
- [ ] 공개 API에 JSDoc/Rustdoc, 매개변수/반환값 문서화
- [ ] 사용 예제 포함, 에러 상황 문서화
